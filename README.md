# SecureMind Nepal 🛡️

🌐 **Live Demo:** [https://secure-mind-nepal.vercel.app/](https://secure-mind-nepal.vercel.app/)

**SecureMind Nepal** is a dedicated web platform designed to educate and empower Nepali citizens for a safer digital journey. With rapid digitalization, the need for cyber awareness is more critical than ever. This platform serves as a centralized resource to help users understand common cyber threats, their digital rights under Nepali law, and the best practices to secure their online identity.

## 🌟 Key Features

The website provides several essential features to promote digital safety:

- **Bilingual Interface:** Entirely translated and accessible in both **English** and **Nepali** to reach a wider audience across Nepal. Users can toggle the language instantly from the navigation bar.
- **Light & Dark Mode:** A built-in theme toggle for comfortable reading in any lighting condition.
- **Common Cyber Threats:** A dedicated section explaining prevalent threats in Nepal, such as:
  - Phishing Scams
  - OTP (One-Time Password) Fraud
  - Social Media Hacking
  - Cyberbullying
  - Identity Theft
  - Investment Scams
- **Digital Rights & Responsibilities:** An interactive accordion guide explaining the privacy rights of citizens, the Electronic Transactions Act (ETA) 2063, and ethical digital conduct.
- **Safe Digital Practices:** Quick, actionable tips for improving personal cybersecurity (e.g., using strong passwords, enabling 2FA, using secure connections).
- **Report Cyber Crime:** A comprehensive guide on how to report cybercrimes in Nepal. It includes:
  - Emergency Helpline (1144)
  - Nepal Police Cyber Bureau Contact Details
  - A secure mock-up mailbox form to help users structure their incident reports before officially submitting them to the authorities.

## 🛠️ Technology Stack

This is a modern, responsive, and lightweight web application built using standard web technologies without heavy frameworks:
- **HTML5** for semantic structure.
- **Vanilla CSS3** for styling, incorporating modern aesthetics like glassmorphism, smooth animations, and CSS variables for theme switching.
- **Vanilla JavaScript** for interactive elements such as language translation, theme toggling, intersection observers (scroll reveal animations), and dynamic statistics counting.

## 🚀 How to Run Locally

Since this is a static website, you don't need any complex server setup to run it locally.

1. Clone or download the repository to your local machine.
2. Open the project folder (`Web wizard`).
3. Double-click on the `index.html` file to open it in your default web browser.

Alternatively, you can use a local development server like the "Live Server" extension in VS Code for a better live-reload experience.

## 📜 Disclaimer
The "Report Cyber Crime" form acts as a structural guide to help victims organize their information and evidence. For official actions and FIR registrations, victims must contact the Nepal Police Cyber Bureau directly via **1144** or email at **cyberbureau@nepalpolice.gov.np**.
